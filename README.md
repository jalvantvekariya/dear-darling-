# A Special Question ❤️

A cute, interactive, single-page proposal website built with Vanilla HTML, CSS, and JavaScript.

## Customization

1. **The Letter**: Open `script.js` and look for `const letterText = "..."`. Change the message to your own heartfelt words.
2. **Music**: Place your desired `.mp3` file inside the `assets/` folder and name it `music.mp3`.
3. **Fonts & Colors**: You can easily change the color variables at the top of `style.css`.

## How to Host on GitHub Pages (Free)

1. Create a GitHub account if you don't have one.
2. Create a new repository (name it something like `my-proposal`).
3. Upload all these files (`index.html`, `style.css`, `script.js`, and the `assets` folder) to the repository.
4. Go to your repository **Settings**.
5. On the left sidebar, click on **Pages**.
6. Under "Build and deployment", select **main** branch and click **Save**.
7. Wait a couple of minutes, refresh the page, and GitHub will provide you with a live URL link you can send to her!
